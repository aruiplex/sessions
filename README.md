# SessionSwitch - 网站多账号登录会话切换器 (Chrome / Edge 扩展)

**SessionSwitch** 是一款轻量、强大且安全的浏览器扩展（基于 Chrome Manifest V3），专用于解决在同一个网站上需要频繁切换多个账号的问题。

---

## 🌟 核心功能特性

1. **三维凭证完整捕获与恢复**：
   - **Cookies**：完整支持普通 Cookie、`HttpOnly` Cookie、`Secure`、子域名共享 Cookie 等。
   - **LocalStorage**：支持现代前端 SPA 单页应用、JWT Token、用户状态持久化数据。
   - **SessionStorage**：临时会话数据同步保存与恢复。
2. **一键无缝切换**：
   - 点击目标账号的「⚡ 切换至此账号」，插件自动清理旧会话、写入新凭据并强制刷新页面，秒级生效。
3. **凭据覆盖更新**：
   - 当网站 Token 过期、更新密码或会话刷新后，点击「更新」即可用最新状态覆盖已有账号，无需重新创建。
4. **一键注销回到未登录**：
   - 提供「注销退出」功能，一键清空该站全部 Cookie 与 Storage 并刷新，方便测试未登录或切换新账号。
5. **多站点集中管理与搜索**：
   - 「全部站点」标签页可集中浏览、搜索和管理所有网站已存的账号档案。
6. **备份与跨设备迁移**：
   - 支持全量或单账号导出为 JSON 备份文件。
   - 支持「合并模式」与「覆盖模式」导入恢复。
7. **纯本地安全隐私**：
   - 100% 运行于本地浏览器内部（`chrome.storage.local`），**绝不上传任何网络服务器**，登录凭据完全由您自己掌控。

## 🚀 安装步骤（只需 30 秒）

本扩展适用于 **Google Chrome**、**Microsoft Edge**、**Brave**、**Arc** 等所有基于 Chromium 内核的现代浏览器。

### 第 1 步：打开浏览器的扩展管理页
- **Chrome**: 在地址栏输入 `chrome://extensions/` 并回车。
- **Edge**: 在地址栏输入 `edge://extensions/` 并回车。

### 第 2 步：开启「开发者模式」
- 在扩展管理页面的右上角（Edge 为左侧边栏），开启 **开发者模式 (Developer mode)** 开关。

### 第 3 步：加载扩展程序
- 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)** 按钮。
- 在弹出的文件选择器中，选中当前目录：
  ```
  /Users/aruix/Documents/sessions
  ```
- 确认后，浏览器工具栏即可看到 **SessionSwitch** 图标！建议点击拼图图标将本扩展 **固定 (Pin)** 到工具栏以方便使用。

## 📖 使用指南

### 1. 保存账号
1. 在浏览器中打开您要多开的网站（如 GitHub、知乎、微博、B站、管理后台等），并正常登录第一个账号。
2. 点击右上角 **SessionSwitch** 插件图标。
3. 点击 **「➕ 保存当前账号」**。
4. 在弹出的对话框中输入备注名称（如 `主号 - 个人` 或 `测试账号 A`），点击确认保存。

### 2. 切换账号
1. 保存好多个账号后，打开插件弹窗。
2. 点击对应账号右侧的 **「⚡ 切换至此账号」**。
3. 插件会自动替换当前网站的 Cookie 与 LocalStorage 并自动刷新网页，网页立即以该账号状态展示。

### 3. 录入下一个新账号（向导模式）
1. 在插件弹窗顶部点击 **「✨ 清空并录入新账号」**。
2. 插件会自动彻底清空当前网站的 Cookie、LocalStorage、SessionStorage，以及关联单点登录系统的票据（如西浦统一认证 SSO 等），并自动刷新网页回到纯净登录状态。
3. 弹窗会显示绿色的 **「新账号录入中」** 指引提示。
4. 此时在网页中正常输入或选择你的下一个账号登录。
5. 登录成功后，再次打开插件，点击 **「➕ 保存当前账号」**（如命名为 `李明 - 账号 2`），即可收录成功！

### 4. 更新凭证
- 若某个账号在长时间使用后换绑了信息或刷新了登录态，在登录状态下点击该账号卡片上的 **「更新」** 按钮即可一键覆盖更新。

### 5. 跨 Chrome Profile 自动实时共享（全自动无感）
- 插件现已标配 **本地跨 Profile 实时同步中间件**。
- 数据在本地统一存放在 `~/.sessionswitch/shared_sessions.json`。
- **你在 Profile A 中保存或更新的账号，打开 Profile B 或 Profile 6 时插件会自动实时双向同步，无需任何手动导出或导入！**
- 本地守护进程通过 macOS LaunchAgent 在后台静默运行（仅监听本地 `127.0.0.1:49152`，内存占用极小约 15MB，无任何外部网络暴露）。
- 管理脚本：
  - `./install_service.sh`：自动配置并启动后台守护服务（已自动为你安装并运行）。
  - `./uninstall_service.sh`：一键停止并卸载后台服务。

### 6. 手动备份与跨设备迁移
- 点击顶部 **「备份/导出」** 标签：
  - **导出所有账号凭证**：生成包含所有站点账号的 JSON 备份。
  - **选择备份文件导入**：在更换电脑或重装浏览器后一键恢复全部账号。
